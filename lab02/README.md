# Лабораторная работа 2. Классы и инкапсуляция

Вариант: инженерия систем искусственного интеллекта.
Условие: [lab02-domain-model.md](../assignments/lab02-domain-model.md).

## Подготовительная часть: BankAccount

Счёт хранит баланс и предоставляет методы `deposit`, `withdraw`, `getBalance`.
Инвариант: баланс всегда находится между 0 и `Integer.MAX_VALUE`.
Начальный баланс неотрицательный; суммы пополнения и списания положительные.
Нельзя списать больше остатка или пополнить счёт с переполнением int.
Ошибочная операция выбрасывает `IllegalArgumentException` и сохраняет баланс.
Поле `balance` приватное; setter отсутствует.

## Обязательная часть: DataSample

`DataSample` — одно наблюдение: идентификатор, метка, статус и массив числовых признаков.
Например, `id = "s1"`, `label = "cat"`, `features = {2, 4}`.

Инварианты:

- `id` и `label` не равны null, не пустые и не состоят только из пробельных символов;
- `status` не равен null;
- `features` не равен null, содержит хотя бы один элемент;
- признаки — конечные числа double: без NaN и бесконечностей; отрицательные значения разрешены;
- массив нельзя изменить снаружи: конструктор и `getFeatures()` создают копии.

Ошибочные аргументы вызывают `IllegalArgumentException`.
Идентификатор, метка и ссылка на внутренний массив объявлены `private final`.
`final` у ссылки не делает массив неизменяемым, поэтому дополнительно нужны копии.
Универсальных setters нет; статус меняется только через `changeStatus`.

Статусы выбраны для этой реализации, поскольку условие не задаёт их названия:

- `NEW` — новое наблюдение;
- `READY` — готовое;
- `REJECTED` — отклонённое.

`isReady()` проверяет равенство статуса `READY`. Переходы разрешены между любыми
статусами: дополнительных ограничений в задании нет.
`averageFeatures()` возвращает среднее. Каждое значение делится на длину массива
перед сложением, чтобы избежать переполнения промежуточной суммы на больших числах.
Как и другие вычисления с double, результат может содержать погрешность округления.
Модели ничего не читают из консоли и ничего не печатают.

## Файлы и запуск

Код: `src/main/java/edu/course/lab02/BankAccount.java`, `DataSample.java`, `SampleStatus.java`.
Проверки: `src/test/java/edu/course/lab02/BankAccountTest.java`, `DataSampleTest.java`.

Требуется JDK 25. Из корня репозитория:

```bash
./mvnw -pl lab02 test
```

Windows PowerShell:

```powershell
.\mvnw.cmd -pl lab02 test
```

В IntelliJ IDEA можно запустить класс тестов зелёным треугольником рядом с его названием.
Отдельный `main` для выполнения лабораторной не требуется.
