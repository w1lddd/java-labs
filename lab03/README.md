# Лабораторная работа 3. Интерфейсы и полиморфизм

Вариант: инженерия систем искусственного интеллекта.
Условие: [lab03-polymorphism.md](../assignments/lab03-polymorphism.md).

## Подготовительная часть

`DiscountPolicy` задаёт метод `apply(price)`. `NoDiscount` сохраняет цену,
`PercentDiscount` применяет процент скидки из диапазона от 0 до 100.
`PriceCalculator` получает политику через конструктор и вызывает её метод.
Например, цена 100 со скидкой 20% становится равной 80.
Цена должна быть конечной и неотрицательной, процент — конечным.

## Обязательная часть

`NormalizationStrategy` задаёт метод `normalize(values)`.

- `MinMaxNormalization`: `(x - min) / (max - min)`, результат от 0 до 1.
  Для одинаковых значений возвращает нули, чтобы не делить на ноль.
- `MeanCenteringNormalization`: `x - mean`, где `mean` — среднее элементов.
  Значения после обработки в среднем примерно равны нулю.
- `FeatureProcessor` хранит поле типа `NormalizationStrategy`, получает реализацию
  в конструкторе и передаёт ей вектор в методе `process`.
- `DataSample` — минимальная независимая модель из условия: хранит только признаки,
  копирует массив при создании и в `getFeatures()`.

Один вектор `{10, 20, 30}` даёт `{0, 0.5, 1}` при min-max и `{-10, 0, 10}`
при центрировании. Чтобы поменять поведение, передайте другую стратегию
при создании `FeatureProcessor`; его код менять не требуется.

`null`, пустые массивы, NaN и бесконечности вызывают `IllegalArgumentException`.
Обе стратегии создают новый массив. Исходные данные сохраняются, в том числе
при ошибке. Конструкторы обработчиков отвергают `null` вместо стратегии.

В min-max при переполнении разности `max - min` числа предварительно делятся
на 2. При вычислении среднего каждое слагаемое делится на количество элементов
до сложения. Переполнение арифметики центрирования вызывает `ArithmeticException`.
Вычисления с `double` допускают погрешность округления.

Модуль не зависит от `lab02`. Дополнительная третья стратегия не включена.

## Запуск

Требуется JDK 25. Из корня проекта:

```bash
./mvnw -pl lab03 test
java -cp lab03/target/classes edu.course.lab03.Demo
```

В IntelliJ IDEA откройте корневой `pom.xml` как Maven-проект и выберите JDK 25.
Для показа откройте `lab03/src/main/java/edu/course/lab03/Demo.java`
и нажмите зелёный треугольник рядом с `main`.
Проверки находятся в `lab03/src/test/java/edu/course/lab03/`;
их также можно запустить через Maven → lab03 → Lifecycle → test.

Проверено 35 JUnit-тестов: скидки и границы процента, две нормализации,
смена реализации через конструктор, сохранность массивов и ошибочные аргументы.
